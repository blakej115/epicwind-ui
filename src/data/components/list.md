---
title: "List Component"
slug: "component/list"
---

The list component is intended for displaying a list of items. It's intended to be used in the `nav` and `bar` components. but it can used in other places as well.

## Basic Usage

<div class="not-content">
  <ul class="list">
    <li class="item">
      <a class="link" href="#">
        Home
      </a>
    </li>
    <li class="item">
      <a class="link" href="#">
        About
      </a>
    </li>
    <li class="item">
      <a class="link" href="#">
        Blog
      </a>
    </li>
    <li class="item">
      <a class="link" href="#">
        Contact
      </a>
    </li>
  </ul>
</div>
